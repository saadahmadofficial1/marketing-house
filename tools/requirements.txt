# Python dependencies for the published tools in this folder.
#
# How this list was made: every import in every tools/*.py was parsed (Python's
# ast module) and each third-party module was matched to the version installed
# in the workspace's main tool environment (Python 3.9). Only packages a tool
# actually imports are listed, and only versions that environment really has
# are pinned. Standard-library modules are not listed.
#
#   python3 -m venv .venv && .venv/bin/pip install -r tools/requirements.txt
#
# Most tools need only a few of these. Each tool's docstring says what it uses.
#
# System tools (not pip):
#   - ffmpeg + ffprobe: almost every video and audio tool shells out to them.
#   - Xcode command-line tools (swiftc): builds the on-device OCR helpers from
#     sa_ocr.swift and sa_ocr_bounds.swift, e.g.
#       swiftc -O tools/sa_ocr.swift -o tools/bin/sa_ocr
#   - exiftool (optional): camera serial numbers in sa_sort.py; mdls is used otherwise.
#   - Ollama with a local vision/text model: sa_translate.py, sa_see.py, sa_qa.py,
#     sa_cutsheet.py, sa_boxcheck.py, sa_hub.py, sa_reel.py, sa_inspect.py,
#     sa_visualmem.py and sa_video_style_read.py talk to it on localhost.
#   - Node.js + Playwright: the headless renderer sa_html_card_render.mjs
#     (edit the Playwright path at the top of that file for your machine).
#   - tkinter (ships with python.org builds; Homebrew needs python-tk) for the
#     small windows in sa_desk.py and sa_eyes_pad.py.
#
# The Fish Audio voice kit is self-contained, with its own set-up script:
#   ../kits/fish-voice-kit/README.md
#
# No third-party code is vendored in this folder.
