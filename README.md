## How I work

- **Human in the loop.** AI does the heavy lifting; I set the creative bar and approve every release.
- **Facts first.** Numbers, names and claims are checked against sources before anything is published.
- **Privacy by default.** Client, company and personal data never leave private systems. This page shows outcomes only.
- **Two-agent workflow.** One AI builds, another reviews, with shared memory so nothing is lost between sessions.
