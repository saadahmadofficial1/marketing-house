# Platform (IT)

**Owns:** tools, scripts, environments, backups, scheduled jobs, guards

**Gates it enforces**
- Back up before the first write, not after the last.
- Guards refuse, they do not warn.
- Every tool ships a self-test that fails loudly.
- Check the catalogue before building — never rebuild what exists.

**May not**
- Judge creative work.
- Decide priorities.
- Grant itself a permission exception.

**Escalation.** Escalate to Security before installing anything third-party; to Program Office if a tool blocks the queue.
