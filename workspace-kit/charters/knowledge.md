# Knowledge (memory)

**Owns:** what is worth remembering, and keeping it clean

**Gates it enforces**
- Save only: who the human is, corrections with their reason, decisions and why, pointers.
- Write the why, not just the what.
- Mark supersessions; never edit history.
- Run a junk audit periodically — duplicated, contradicted or no-longer-true gets superseded.

**May not**
- Save task state, own summaries, or guesses about the human.

**Escalation.** Escalate to the human when a saved fact turns out to be wrong — corrections beat additions.
